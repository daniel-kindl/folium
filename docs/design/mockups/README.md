# Folium visual mockups

Design reference for the Open Leaf visual design issue. These files are not app code.

Daniel chose logo concept A, Open leaf, on 2026-11-11.
The approved base from 2026-11-03 stays the same: forest-and-paper tokens, Noto Sans, and Lucide icons.

## Contents

- `logo/`: SVG layers and marks. Use `concept-A-*` for implementation. Concepts B and C are rejected alternatives.
- `screens/`: 16 screens, light and dark, at 412 x 915 dp and 2x.
- `sheets/`: Overview, logo, palette, type, components, flow and contact sheets.
- `tokens.proposed-additions.json`: Proposed token additions. Approved token values do not change.
- `contrast.csv` and `contrast.md`: 116 contrast pairs. All pass.
- `strings.md`: User-facing strings used in the mockups.
